# ⚙️ Pipeline Architecture
Design the pipeline with the following components:

## 1. Ingestion Layer
- File discovery and metadata capture
- Deduplication using hashing
- Logging and retry mechanisms

## 2. Extraction Layer
Extract ALL content types from PDFs:
- Text (use PyMuPDF / pdfplumber)
- Tables (use camelot / tabula)
- Images (extract images)
- OCR on images (use Tesseract / EasyOCR)
- Image description (use vision-capable model or captioning model)

## 3. Processing Layer
- Clean and normalize text
- Chunk content intelligently (semantic chunking preferred)
- Extract metadata:
  - Title
  - Author (if available)
  - Keywords
  - Topics
  - Entities (NER)

## 4. Embedding Layer
- Generate embeddings using a configurable model (e.g., sentence-transformers or API)
- Store embeddings with references to chunk IDs
- Support vector DB compatibility (FAISS / Pinecone-ready format)

## 5. AI Enrichment Layer (Use GroQ LLM)
Use :contentReference[oaicite:1]{index=1} LLM APIs with optimized prompts:

### a. Knowledge Graph Generation
- Output JSON format:
  {
    "entities": [],
    "relationships": [],
    "attributes": []
  }
- Ensure deduplication and normalization

### b. FAQ Generation
- Generate high-quality Q&A pairs
- Cover key concepts and edge cases
- Output format:
  [
    {"question": "", "answer": ""}
  ]

### c. DOK-Based Question Generation
Generate questions based on Depth of Knowledge:

- Level 1: Recall (facts, definitions)
- Level 2: Concepts (explain, compare)
- Level 3: Strategic thinking (analyze, justify)
- Level 4: Extended reasoning (multi-step, real-world application)

Output format:
{
  "level_1": [],
  "level_2": [],
  "level_3": [],
  "level_4": []
}
