You are a senior Python architect and AI safety engineer.

Design and implement a **production-grade, reusable Guardrails Framework in Python** that supports both **Input Guardrails (pre-LLM)** and **Output Guardrails (post-LLM)** for any LLM-based system.

---

# 🎯 Core Requirements

## 1. Guardrail Execution Logic
* Each guardrail is assigned a unique **sequenceId** (power of 2: 1, 2, 4, 8, 16, …).
* A **mapped_number (bitmask)** determines which guardrails are active.
* Execute a guardrail ONLY IF:
  mapped_number & sequenceId != 0
* This enables scalable, configurable, and dynamic guardrail execution.

---

Design a modular, extensible architecture with:
### Core Components:
* `BaseGuardrail` (abstract class)
* `InputGuardrail` and `OutputGuardrail` (inherit from Base)
* `GuardrailExecutor`
* `GuardrailRegistry`
* `GuardrailResult` (status, score, flags, message)
* `PipelineContext` (input, intermediate, output, metadata)

## 3. Input Guardrails (Pre-LLM Layer)
Implement the following guardrails:

5. SQL Injection Prevention
6. Intent Alignment Verification

Each guardrail should:
* Return structured result (pass/fail, confidence score, reason)

## 6. Execution Flow
### Step-by-step pipeline:
1. Receive input prompt
2. Execute **Input Guardrails** (based on bitmask)
3. If passed → invoke LLM
4. Capture response
5. Execute **Output Guardrails**
6. Return final validated response
