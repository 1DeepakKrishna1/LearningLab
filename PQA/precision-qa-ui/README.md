# Precision QA - Frontend

This is a minimal React frontend scaffold created to match the user's request.

Install dependencies and run (Windows PowerShell):

```powershell
cd c:\allCode\code_DK\PQA\precision-qa-ui
npm install
npm start
```

Notes:
- Tailwind requires PostCSS config and the `tailwindcss` package (included in package.json). After installing, the dev server will process Tailwind.
